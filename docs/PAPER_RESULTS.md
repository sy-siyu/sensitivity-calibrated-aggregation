# Current paper results and code map

This map connects the paper's empirical Tables **3–4** and Figures **2–5** to reproduction commands and outputs. Stable LaTeX labels identify each item if numbering changes. Figure 1 is the conceptual provider–analyst pipeline and is not generated from an experimental report.

The output basenames `table1_*` and `table2_*` correspond to manuscript Tables 3 and 4. Additional width diagnostics use `table3_*` and have no table number in the paper.

## Complete execution

From an installed checkout:

```sh
python -m pip install -e '.[plots]'
python -m sca_reproduction prepare-data --directory data --dataset all
python -m sca_reproduction run all --workspace outputs/paper
python -m sca_reproduction report all --workspace outputs/paper
python -m sca_reproduction paper-tables --workspace outputs/paper
for study in efficiency split release precision; do
  python -m sca_reproduction plot "$study" --workspace outputs/paper
done
```

Full execution can take many CPU-hours and substantial storage. `smoke` checks execution only and cannot supply these paper outputs. All paths below are relative to `outputs/paper/`.

Exact rational evidence remains in generated JSON artifacts. Publication tables and figure-coordinate CSVs contain display floats/rounding. The table and plot assemblers validate complete denominators before writing output and never launch experiments or recompute uncertainty.

### Table 3 interpretation

The assignment rows use unknown masses, cap `3/2`, all 48 conditions and 100 replications per condition (4,800 datasets). Achieved compression is `100*(K-count)/K`; oracle compression is `100*(K-oracle_count)/K`; coupling gain is the paired `100*(count_independent-count_coupled)/K`; and oracle gap is `100*(count-oracle_count)/K`. Each compression is normalized by that dataset's support size before the existing equal-condition average is taken, so counts from different `K` values are never pooled first. Do not treat the raw assignment `oracle_gap` count as already normalized.

The oracle uses the true assignment law within the same realized candidate family, retaining the sample's estimated order for Contiguous and Combined. The Allocation control and Fixed-group pooled rows keep observations, realized families, order, and cap fixed. Their uncertainty comes from the efficiency reporter's replication-index condition averages. Recoveries always refer to the oracle count for the row's own family; the zero recoveries across all three confidence constructions refer specifically to the Combined family. Population truth is diagnostic and never enters operational selection.

### Table 4 interpretation

The development panel contains 480 datasets and selects `1/3` from `{1/10,1/5,1/3,1/2,2/3}`. Table 4 uses only evaluation replications 10–99: 90 per condition and 4,320 datasets total. Current rounded compression percentages are A–F: `14.47, 8.78, 9.34, 14.65, 22.72, 24.20`. The paired F−A contrast is `9.73 [9.57, 9.89]` percentage points.

The report is generated by the five-fraction `relevance` study. Equal-condition intervals use the fixed-condition paired design. The first four signed increments depend on the specified sequence and are not separately identified causal effects.
