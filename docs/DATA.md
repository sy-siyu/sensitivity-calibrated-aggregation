# Public covariates and the finite benchmark

Run `python -m sca_reproduction prepare-data --directory data` from the checkout. The input is [CEVAE's IHDP replication-1 CSV](https://github.com/AMLab-Amsterdam/CEVAE/blob/master/datasets/IHDP/csv/ihdp_npci_1.csv), downloaded directly from its public source. Required SHA-256:

```text
2bdc8b94fdf2f669b1d3d49325fd9359d88418566545003867841312a1653411
```

The command verifies this checksum, 747 rows and 30 columns. For offline setup, place the matching file at `data/ihdp_npci_1.csv`. Downloads remain untracked.

The [CEVAE loader](https://github.com/AMLab-Amsterdam/CEVAE/blob/master/datasets.py) defines the first five columns as treatment and outcome quantities, with covariates beginning at zero-based column 5. The [NPCI variable definitions](https://github.com/vdorie/npci/blob/master/examples/ihdp_sim/data.R) give the covariate order: birth weight (`bw`), head circumference, preterm, birth order, neonatal health, maternal age (`momage`), infant sex, and others. The benchmark uses only CSV columns 5, 10 and 11, interpreted in this order. It uses the supplied covariate coordinates; it does not reinterpret standardized coordinates as physical units. Original treatment and outcome columns are ignored.

Before drawing calibration or outcome samples, the **complete 747-record reference population** defines states by birth-weight quartile × maternal age above median × binary sex. Quantiles use exact decimal fractions, linear interpolation at index `(747-1)q`, and equality belongs to the lower bin. Maternal age uses strict `>` median. Occupied tuples are sorted lexicographically into immutable state IDs. This declares 16 supported states and positive mass `reference state count / 747`. An unobserved sampled state remains in the declared support.

Assignments have propensity `(8 + 3*birthweight_bin + 2*age_bit + sex)/32`. Treated binary-outcome means are `(12 + birthweight_bin + age_bit + sex)/32` for the low-heterogeneity profile, and `1/8` or `7/8` according to even/odd tuple parity for the high-heterogeneity profile. Control outcomes use Bernoulli `1/2`. `G=2` is the raw sensitivity budget conditional on this declared state S; the generated assignment law is conditionally independent and has actual sensitivity 1. Population targets are computed from this fixed law, not from a real-world causal interpretation of IHDP.

Calibration and outcome cohorts are independent resamples of reference records, with independent component streams. Empirical masses are non-dyadic; the sampler resamples uniform record IDs and never rounds masses to a dyadic grid. Known finite support applies to this benchmark population only, not an unknown real-world population.

Controlled experiments require no download. Their population laws, exact stored-binary convention, trees and random streams are generated by the source modules described in [reproduction details](REPRODUCTION.md).
